Simple DirectMedia Layer

  • Provides all the system abstractions we need:
    • Windowing
    • Input (Keyboard, Mouse, Touch, Game Controllers)
    • GPU Accelerated Rendering
    • Audio
    • Filesystem
    • Multi-threading

Simple DirectMedia Layer

  • Has several useful extra libraries
    • SDL_image
      • Loads many different formats
      • Can load directly as textures
    • SDL_ttf
      • Loads TrueType fonts
    • SDL_mixer
      • Loads many different formats
      • Exposes simple API for playback and mixing
